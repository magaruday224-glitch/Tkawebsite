# The Kiran Academy — HTML/CSS/JS Website

A responsive, original front-end website concept built from publicly available information on the official Kiran Academy website.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — navigation, course filters, counters, FAQ, demo form interaction and back-to-top button

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Important
The demo form is intentionally front-end only. Connect it to your backend/API before using it for real enquiries.

Content such as courses, branch addresses, phone numbers and headline statistics was checked against the official website on October 1, 2026. Verify live details before production deployment.
